# Sejarah Tingkatan 4 – Kad Kilat, Kuiz & KBAT

Aplikasi ulang kaji Sejarah Tingkatan 4 (KSSM) untuk telefon: kad kilat, kuiz pilihan jawapan, ujian pecutan dan latihan KBAT (objektif dan esei).

- Satu fail sahaja: `index.html` (tiada pemasangan, berfungsi di luar talian selepas dibuka).
- Kemajuan pelajar disimpan dalam pelayar telefon masing-masing.
- Kandungan berdasarkan Buku Teks Sejarah Tingkatan 4 KSSM. Cadangan jawapan esei KBAT bukan skema rasmi.

## Kemas kini

Gantikan `index.html` dengan versi baharu, kemudian commit. GitHub Pages akan dikemas kini dalam 1–2 minit.
